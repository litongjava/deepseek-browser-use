# 阿里云轻量应用服务器（购买 / 备案）

一次真实任务的产物（2026-09-25）：登录 → 比价 → 选中 2 vCPU / 1 GiB / 30 GiB / 200 Mbps / 华北2（北京）/ 1 年 ￥408.00 → 送到收银台由人付款。
下面每一节都是「不这么写就会踩」的部分，不是命令罗列。

## 一、站点特征

| 项 | 值 |
| --- | --- |
| 产品页 | `https://www.aliyun.com/product/swas` —— 页上的「立即购买」自带 ``regionId`` / ``planId`` / ``duration`` 参数，**是最好的入口** |
| 新版购买台 | `https://swasnext.console.aliyun.com/buy`（React SPA，标题「轻量应用服务器控制台」） |
| 旧版控制台 | `https://swas.console.aliyun.com/` 现在会 **302 到** `swasnext.console.aliyun.com/servers/<地域>`，**没有**可比价的旧版购买页了 |
| 登录页 | `https://account.aliyun.com/login/login.htm`：左侧是「阿里云APP / 支付宝 / 钉钉」扫码；右侧三个**跨域 iframe**（`passport.aliyun.com`）分别是账密、短信、通行密钥 —— 直接读顶层文档是空壳，要 `includeFrames` |
| 收银台 | `https://finance.aliyun.com/order/trade_pay.htm`（下单成功后自动跳转过来） |
| 登录态 | 在共享 profile 里（`start` 回执的 `data.browser.profileDir`）；用 `profileSeenBefore` 判断要不要重新登 |
| 未支付订单 | 控制台右上角「未支付订单 N」，或费用中心订单列表；**收银台页关掉也能从那里继续付** |

套餐 ID 形如 ``swas.s.c2m2s40b1.linux``：``c2`` = 2 vCPU、``m2`` = 2 GiB、``s40`` = 40 GiB 系统盘。**不必猜这个 ID** —— 购买台里点选套餐更省事，`planId` 只在你需要用 URL 直达某个套餐时才写。

## 二、买之前先定：这台机器能不能用于备案

| 条件 | 说明 |
| --- | --- |
| **地域必须是中国内地** | 华北2（北京）、华东1（杭州）、华南1（深圳）等 |
| **中国香港与所有海外节点一律「免备案」** | 新加坡 / 日本（东京）/ 印尼（雅加达）/ 泰国（曼谷）/ 马来（吉隆坡）/ 菲律宾（马尼拉）/ 韩国（首尔）/ 美国（弗吉尼亚、硅谷）/ 德国（法兰克福）/ 英国（伦敦）—— 便宜、带宽大，但**不能备案** |
| **包年包月且购买时长 ≥ 3 个月** | 阿里云的备案服务码要求包年包月、时长 3 个月及以上；只买 1 个月拿不到服务码 |
| 域名与主体 | 域名需境内注册并实名，主体信息走阿里云备案系统；这跟服务器地域无关，但前提是「内地服务器」 |

> **最容易买错的一步**：购买台**默认地域是「新加坡」**，套餐卡上写着「免备案」。不切地域直接下单，就得到一台**永远不能备案**的机器。

## 三、必须这么走的步骤

### 1. 打开购买台（地域别用默认值）

URL 里有 `&`，**在 cmd/PowerShell 里别直接拼命令行**（`&` 会被 cmd.exe 吃掉，只剩第一个参数）：用 `--params @文件.json`

```json
{
  "url": "https://swasnext.console.aliyun.com/buy?regionId=cn-beijing&duration=12"
}
```

```shell
# 用 dsb 客户端发(Windows 在 PowerShell 里要写 dsb)
dsb --port 10049 --id 9001 run go_to_url --params @tmp/nav-buy.json
```

`regionId` 取中国内地（例如 ``cn-beijing`` / ``cn-hangzhou``），`duration` 是**月数**：`1` / `3` / `12`，它决定「应付」那一行算几个月。页面上的「时长」区在 DOM 里**只有一个广告卡**，真正的时长由这个 URL 参数决定 —— 想比 3 个月与 1 年的价，就换参数重新打开一次。

### 2. 关掉挡路的引导层

新版控制台会弹一个「计算 AI 助手」引导层。`get_modals` 对它是 `count=0`（不是标准弹窗），直接用快照里的「暂不体验」按钮点掉：

```json
{"id":9001,"method":"get_browser_state","params":{}}
{"id":9001,"method":"click_element_by_index","params":{"index":4}}
```

关掉之后元素数会从个位数涨到 90+，购买表单才真正可读。

### 3. 看全套餐：必须点「更多实例」

套餐卡（含「爆款」「更多实例」那种）在快照里是**一整行文本**，没有独立索引，用文本点击：

```json
{"id":9001,"method":"click_element_by_text","params":{"text":"更多实例"}}
```

弹出的浮层会按**月付价格**排序列出当前类型 + 当前地域的全部套餐，读它的文本就是一张价目表：

```
¥ 28/月 BGP 免备案 vCPU 2 vCPU 内存 0.5 GiB 系统盘 20 GiB ...
¥ 35/月 BGP        vCPU 2 vCPU 内存 0.5 GiB 系统盘 20 GiB ...   ← 中国内地最便宜
¥ 40/月 爆款 BGP   vCPU 2 vCPU 内存 1 GiB 系统盘 30 GiB ...
¥ 45/月 BGP        vCPU 2 vCPU 内存 2 GiB 系统盘 40 GiB ...
```

> 同一个「通用型」标签，地域不同列出的套餐也不同：**海外**列里有 ￥28/月 并且都标「免备案」，**中国内地**列里最低是 ￥35/月 且**没有**「免备案」标记 —— 这个标记就是判断能不能备案的直接线索。

点某一行的文本选中它，再点「确认选择」；之后**价格行**会同时给出折合与总价：

```
实例   ¥ 29.75/月   ¥ 357.00/年      ← 2 vCPU / 0.5 GiB / 20 GiB，年付 85 折
实例   ¥ 34.00/月   ¥ 408.00/年      ← 2 vCPU / 1 GiB / 30 GiB（爆款）
```

### 4. 登录（人工扫码）

控制台未登录时会跳到登录页。**不要向用户索要密码**：让人用阿里云APP/支付宝/钉钉扫码。

```json
{"id":9001,"method":"get_element_count","params":{"selector":"[class*=qrcode]"}}
{"id":9001,"method":"get_element_screenshot","params":{"selector":"[class*=qrcode]"}}
```

- 二维码元素的类名里带 ``qrcode``（`[class*=qrcode]` 能命中 3 个，第一个可见的就是二维码，约 145×145、7 KB 上下）；另外两个同类选择器会等满超时，说明命中的是隐藏节点。
- 把回执里的 `data.url`（形如 `/data/9001/shot-5.png`）拼成 `http://<服务端>:10049/...` 贴给用户即可手机扫；二维码有**时效**，失效就 `reload` 后重新截一张。
- 正式的人工接力用 `request_human_input`（把二维码一步交办）+ `bring_to_front` 把窗口带到最前；扫完再 `submit_human_input` / `get_human_input` 记录答复。
- **登录成功怎么确认**：主 frame 的 URL 变成 `swasnext.console.aliyun.com/buy`，购买台右上出现账号与「工作台 / 费用 / 备案 / 工单」。

### 5. 下单到收银台

配置区就三样要确认：**地域**（必须中国内地）、**数量**（默认 1）、**价格行**（折合 / 应付与时长对得上）。然后点页面最下方那个「立即购买」（**不要点时长区广告卡里的那个同名按钮**，两个按钮文本一样，索引靠快照区分：广告卡在 `时长` 区内部，主按钮在页尾、紧挨「点击立即购买即表示您已知悉并同意」）。

成功后跳到 `https://finance.aliyun.com/order/trade_pay.htm`，回执里 `data.url` 的 ``order_id`` 会被日志脱敏成 `***`，这是**正常现象**，不影响页面本身。

### 6. 支付：只能人工

收银台可读到的关键信息：

```
待支付订单   应付 ：￥408.00
<订单号> 轻量应用服务器 ... 地域: 华北2（北京）, 系统镜像: Alibaba Cloud Linux 4,
套餐配置: 2 vCPU | 1GiB 内存 | 30GiB 系统盘 | 不限流量 | 200Mbps 峰值BGP公网带宽 | 1个 IPv4公网地址  1  1 年  ￥408.00
使用账户余额抵扣（ 当前账户余额 ￥79.15 ）
选择支付方式：支付宝 / 赊呗（部分商品不支持）/ 蚂蚁花呗 / 银联在线支付
```

- **不要替用户点「支付」**：支付密码/扫码只能本人完成。用 `request_human_input`（`selector` 指页尾的 `button[type=submit]`）+ `bring_to_front`，把窗口留在收银台，然后等用户回话。
- 想省现金可以先勾「使用账户余额抵扣」（`input[type=checkbox]`，`index` 从快照取），再让人付余额之外的差额。
- **付款完成前别停服务**：`close` / 停服务会连带关掉浏览器，收银台页随之消失（订单不会丢，从控制台的「未支付订单」还能继续付）。

## 四、这个站点特有的坑

1. **默认地域是新加坡、套餐标「免备案」** —— 直接下单 = 买到一台不能备案的机器。切地域的入口是页面上那行「地域」文本（下拉里分「香港及海外」与「中国内地」两组）。
2. **地域下拉里「中国内地」可能是空的**：那说明当前选中的套餐在该地域没有库存/不在售，去「更多实例」里换一个套餐再看，别以为页面坏了。
3. **`&` 被 shell 吃掉**：带查询串的 URL 一律走 `--params @文件.json`，否则只会打开 `...buy?regionId=cn-beijing`（后面的 `planId`/`duration` 全部丢失），时长会退回默认 1 个月。
4. **「时长」不是页面上的控件**：DOM 里那块只有广告卡，时长由 URL 的 ``duration`` 决定。
5. **两个「立即购买」**：时长区的推广卡里也有一个同名按钮，点错了会跳到别的产品活动页。
6. **这个站点的重活最容易撞上 Playwright 的「事件泵伪故障」**：控制台 XHR 极多，`execute_js` / `get_form_state` / `get_element_box` / `go_to_url` / 自动截图会成串报 `Object doesn't exist: response@… / request@…`（对象与本次命令毫不相干）。只读命令服务端现在会**自动重发**并回 `data.spuriousRetry`；`execute_js` 读页面时记得传 `retryOnSpurious: true`；**点「立即购买」「支付」这类动作绝不要重发**。详见主技能第十一节的那一条。
7. **比价的正确口径**：只用「月付排序」那一列读绝对价格（`更多实例` 浮层），再回到购买台看「折合 / 应付」的年付价。不要拿「爆款卡」上那个 `¥ 34/月` 直接乘 12 —— 年付是折后价（￥408 而不是 ￥480）。

## 五、怎么确认每一步真的成了

| 这一步 | 证据 |
| --- | --- |
| 登录成功 | 主 frame URL 变成购买台/控制台，页面出现账号名与「工作台」 |
| 地域切对了 | 快照里「地域」下面那行是 `北京` / `杭州` 等**内地**名字，且套餐行**没有**「免备案」 |
| 套餐选对了 | 价格行同时出现折合与总价（`实例 ¥ 34.00/月 ¥ 408.00/年`），与套餐行的规格一一对应 |
| 下单成功 | URL 跳到 `finance.aliyun.com/order/trade_pay.htm`，页面出现「待支付订单」与「应付 ：￥…」 |
| 付款成功 | 收银台显示支付结果，控制台「未支付订单」归零；轻量控制台的服务器列表里出现这台实例与地域 |
